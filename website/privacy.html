Privacy information

What the project does with information.

This page distinguishes the public static website from the separate NUMPE app and backend. It describes the repository's current implementation and does not promise a retention period or deletion process that has not been defined.

Scope: The public website pages do not require an account and do not connect to the NUMPE backend. The app and backend are separate project components.

Information collected by this website

The static website code does not include analytics scripts, cookies, account forms, or a feature that sends visitor information to the app backend. Your browser may keep ordinary cached website files. If the site is hosted online, the hosting or delivery provider may process request and security logs; the project's hosting configuration and provider retention settings are not established here.

Information processed by the separate app/backend

If you use a connected backend deployment, its current code can process and store:

  • Account registration details: username, email address, and a password hash (the password itself is hashed before it is stored).
  • Session records: a hash of the bearer token, creation and expiry times, and any revocation time.
  • Analysis requests: the analysis type, the first 64 characters of the submitted input, and the resulting risk score, level, explanation, recommendation, and timestamp. Do not submit passwords, payment PINs, one-time passwords, or other sensitive information.
  • Reports: the report type, full description submitted in the report, status, and timestamp.

The repository configures SQLite as the default backend database, but a deployment can override the database path. The current public website does not send data to these endpoints.

Cookies, analytics, and third parties

The public website does not set analytics cookies or embed analytics code. The backend analysis implementation inspected for this page uses the project's local analysis code; this site does not send user content to an AI provider. A deployed hosting provider may handle requests under its own service terms and settings.

Retention and deletion

The project does not define a published retention schedule. The current backend does not expose a user account deletion endpoint, and this website cannot delete backend records. Database operators should manage stored records according to their deployment, applicable requirements, and a documented retention policy.

Contact

No dedicated privacy contact address is published in this project. Do not send sensitive account or payment information through public issue trackers.
